# Ingeniero de Documentación

Responsabilidades:

- Revisar la claridad del README y de los notebooks.
- Verificar que haya instrucciones completas para ejecutar el proyecto.
- Asegurar que los textos expliquen el propósito, los pasos y los resultados.
- Proponer una estructura de documentación accesible para futuros revisores.

Objetivo:

Lograr que el proyecto sea fácil de entender, usar y mantener gracias a buena documentación.
