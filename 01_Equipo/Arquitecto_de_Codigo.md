# Arquitecto de Código

Responsabilidades:

- Revisar la estructura del proyecto y la organización de carpetas.
- Verificar buenas prácticas de codificación y estilo.
- Sugerir mejoras en la mantenibilidad y modularidad del código.
- Proponer convenciones para nombres, configuración y archivos de soporte.

Objetivo:

Asegurar que el código sea claro, consistente y fácil de escalar.
