# Equipo del proyecto Asteroid Classification

Esta carpeta contiene los agentes encargados de mejorar la calidad y revisar el proyecto.

Agentes incluidos:

- `Arquitecto de Codigo`
- `Cientifico de Datos`
- `Astro Fisico`
- `Ingeniero de Documentacion`
- `Estadístico`

Cada agente tiene responsabilidades específicas para asegurar que el proyecto sea limpio, reproducible y bien documentado.
