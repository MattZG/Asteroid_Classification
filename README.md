**Proyecto: Clasificacion de Asteroides**

Este proyecto tenia como objetivo profundizar el uso de modelos de clasificacion, aplicado a un caso con multiples clases.

Además, incluye documentación sobre las propiedades fisicas que fui investigando a medida que exploraba el dataset.

Actualmente se encuentra en stand-by por falta de tiempo, queda por escalar las variables y probar como mulitples modelos de clasificacion (supervisado y no supervisado).
